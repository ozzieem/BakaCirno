# Font Setup Instructions

## For testing purposes, you can download a free pixel font:

1. Go to https://fonts.google.com/specimen/Press+Start+2P
2. Download the font
3. Extract the TTF file
4. Place it in assets/fonts/

## Alternative: Use a placeholder system font

If you don't want to download fonts right now, the code will fall back to the
system default font.

## For the original game feel:

The original game likely used a bitmap/pixel font. Good alternatives:

- Press Start 2P (Google Fonts)
- Pixel Operator (free)
- 04B_03 (free retro font)
- Any monospace font for a clean look
